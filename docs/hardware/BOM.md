## B. 极简验证档（约 ¥1,500）

- 用现成两轮差速小车套件（含电机驱动）
- 主控：树莓派 3B/4B + 便宜 2D 雷达（或先用仿真，真机只验证驱动层）
- 暂不配相机，门牌用键盘/服务模拟

## C. 与仿真的对应关系

| 仿真部件 | 真机对应 | 校准项 |
|---|---|---|
| left/right_wheel_joint | 电机+编码器 | ticks/rev、轮径 |
| lidar_link / scan | RPLIDAR 等 | `frame_id=lidar_link`，角度零位 |
| imu_link / imu | MPU6050/BNO055 | 陀螺零偏、磁力计（可选） |
| camera_link | UVC 相机 | 内参（可选） |
| diff_drive_controller | STM32 速度环 | Kp/Ki/Kd |
| payload_link | 药箱 | 微动开关 → `/medi/load` |

## D. 下单检查

- [ ] 电机与驱动电流匹配（峰值 ≥ 2× 堵转）
- [ ] 雷达供电电压与 USB 供电能力确认
- [ ] 电池容量 ≥ 连续 1 h 仿真同工况
- [ ] 所有串口线/USB 线有固定，防振脱落
