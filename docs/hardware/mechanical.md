# MediBot 机械结构与尺寸

## 1. 与 URDF 对齐的硬约束

| 参数 | 仿真值 | 真机允许公差 | 测量方法 |
|---|---|---|---|
| 轮半径 | 0.048 m | ±0.002 | 卡尺 |
| 轮距 | 0.32 m | ±0.005 | 卷尺（轮触地中线） |
| 底盘长×宽 | 0.42 × 0.28 m | — | — |
| 机身高 | 0.12 m | — | — |
| 离地间隙 | 0.05 m | ≥0.04 | — |
| 整机质量（含电池） | ~6–8 kg | — | 电子秤 |

## 2. 传感器安装

- **雷达**：尽量高于药箱，水平安装，`x=+0.10 m`，扫描平面距地 ≥0.15 m  
- **IMU**：靠近旋转中心，避免电机强磁  
- **相机**：朝前，俯仰 0°，门牌识别距离约 0.4–0.8 m  
- **药箱**：重心尽量靠后轴中间，避免抬头/点头  

## 3. 外形建议

```
        [相机]
      [=====雷达=====]
     +----------------+
     |    药箱 200g   |
     |  +----------+  |
     |  |  电池PCB  |  |
     +--+----------+--+
       (左轮)    (右轮)
          [万向轮]
```

## 4. 装配顺序

1. 底盘骨架 + 轮子（手动转动无卡滞）  
2. 电机固定 → 编码器线固定  
3. 电池/驱动/MCU 底板  
4. 雷达支架（减振垫）  
5. 药箱与微动开关  
6. 整机配平与线束  

## 5. 与仿真一致性检查

改真机任一几何参数后，**必须同步**：

1. `medinav_description/urdf/medibot.urdf.xacro`  
2. `medinav_navigation/config/diff_drive_controller.yaml`  
3. `medinav_hardware/config/medibot_hw.yaml`  
4. 本文表格
